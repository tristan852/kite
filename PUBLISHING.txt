Publishing steps of a new Kite release
(in case I ever forget or someone else would like to know)

0) prerequisite: enhance or improve the solver and or project in some way
0.1) prerequisite: check that everything functions correctly (by trying it out and by running the unit tests)

1) increase the version number (best done using the 'Replace in Files'-tool in Intellij IDEA)
    - don't forget to update the versions in bucket/kite.json and Formula/kite.rb!
    
    - version format is MAJOR.MINOR.PATCH
    - increase MAJOR if: the project underwent a complete rewrite or the purpose of the project changed in a very meaningful way
    - increase MINOR if: the project has changed in a way that is noticeable to an end-user (e.g. new API method)
    - increase PATCH if: a change was done that is not directly visible from the outside

2) publish the new release to Maven Central (done via publishToMavenCentral Gradle task)
    - this requires access to the Maven Central account as well as the private key used for signing

3) push all changes to the GitHub repository

4) publish CLI release to Homebrew and Scoop
    - download the binaries built by GitHub actions on the latest commit: https://github.com/tristan852/kite/actions/workflows/graalvm-native.yml
    - unpack the archives if they have been zipped
    - compute SHA256 for all archives (e.g. Windows PowerShell: "Get-FileHash .\kite-1.0.0-windows-x64.zip -Algorithm SHA256")
    - update Formula/kite.rb (in https://github.com/tristan852/homebrew-kite) with new SHA256 hash for Linux and macOS
    - update bucket/kite.json (in https://github.com/tristan852/scoop-bucket) with new SHA256 hash for Windows

5) push all changes to the GitHub repository again (all three repos)

6) optional: refresh the javadoc.io page over at https://javadoc.io/doc/io.github.tristan852/kite

7) optional: refresh the JavaDoc README-badge using 'curl -w "\n" -s -X PURGE https://camo.githubusercontent.com/...'

8) create a new GitHub release for the CLI tool
    - download the binaries built by GitHub actions on the latest commit: https://github.com/tristan852/kite/actions/workflows/graalvm-native.yml
    - unpack the archives if they have been zipped
    - create a new GitHub release with following details:
        - tag: create new tag given the version (e.g. "v1.0.0")
        - title: "Kite vX.X.X CLI tool"
        - description: "This release provides the prebuilt binaries for the Kite CLI tool. Performance and throughput may be lower when using the solver through the CLI compared to using it as a library."
        - attached binaries: every archived (!) binary produced by the latest workflow run (downloading from the workflow run might compress the archives again -> unpack them)
